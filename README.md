# Drzewo rodziny Fleury – Zaniewski

Interaktywne drzewo: otwórz `index.html` (albo stronę GitHub Pages tego repozytorium).

- `data/graph.json` – dane: osoby (węzły), relacje (krawędzie), fakty ze statusem i źródła
- `RESEARCH.md` – notatki badawcze, sprawdzone ślepe uliczki, otwarte wątki
- `vendor/elk.bundled.js` – biblioteka układu grafu (elkjs, EPL-2.0)

Statusy faktów: C = potwierdzone dokumentem, P = prawdopodobne, H = hipoteza, FAM = przekaz rodzinny, X = odrzucone.
